---
name: github-contribution-analysis
description: Assess public repository contribution substance.
---
Verify account identity separately through evidence-backed anchors. Inspect authored diffs, merged pull requests, review substance, issue context, release notes, and repository links. Commit count is only a discovery signal. Distinguish authorship, review, maintenance, and project ownership; one does not prove another. Clone only when bounded API evidence cannot answer a material patch/history question. Separate demonstrated public work from unverifiable internal ownership or business impact.
