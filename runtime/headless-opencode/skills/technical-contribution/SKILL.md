---
name: technical-contribution
description: Verify public technical contribution substance without turning activity into ownership.
compatibility: opencode
---

Load this method only for code, repository, package, or technical-project claims. Resolve account identity separately. Prefer authored diffs, merged pull requests, substantive reviews, issues, release notes, package records, and repository documentation. Commit count is discovery, not proof of impact. Distinguish activity, authorship, review, maintenance, ownership, leadership, and business impact; evidence for one does not establish the others. Clone only when bounded API records cannot resolve a material patch or history question. Internal responsibility may remain weak or unresolved.
