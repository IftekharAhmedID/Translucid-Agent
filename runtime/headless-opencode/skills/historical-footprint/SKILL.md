# Historical footprint

Load this method only for a remaining Tier-A historical gap.

Load it only after discovery identifies a relevant person, project, URL, or
domain that can make the historical route concrete.

Do not use it for routine chronology, Tier-B detail, or speculative archive
browsing.

Define the historical material predicate first.

Keep employer, formal title, work scope, team, location, start/end dates, and
technical contribution separate when the evidence has different authority or
timeframes.

Prefer contemporaneous primary, employer, institutional, governance,
repository, mailing-list, conference, release, or registry records.

For a historical employment or technical claim, bound publication dates around
the claimed interval before searching.

Use the wider interval only when transition uncertainty itself is material.

Search broad-to-narrow:

1. Start with the person and organization or project.
2. Learn dated vocabulary, source families, and canonical URLs.
3. Use a date-bounded deep route only for the remaining material gap.
4. Fetch decisive leads directly and inspect the captured source locally.

Use `additionalQueries` only with a deep route and only when several known
query variants are genuinely useful for the same material cluster.

Use `excludeDomains` when subject-origin or already-used sources would conceal
an independent route.

Use archives only after a useful historical URL or domain is known.

An archive capture is evidence of the captured page at its capture date, not
automatic proof of every historical assertion.

Resolve identity before attributing a historical account, message, or record.

Do not treat a matching name as sufficient.

Make one origin-chase or falsification route when the historical claim is
consequential and not already established by a dispositive record.

Stop after an additional materially different route produces no new source
family.

Do not revive any per-claim provider-call quota.

Do not pad citations, repeat equivalent searches, or search archives merely
because they are available.

If the gap remains, preserve a precise unresolved claim with its temporal and
public-evidence limits.
